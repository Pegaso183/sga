# 04 · Glosario

| Término | Definición |
|---|---|
| SGA / WMS | Sistema de Gestión de Almacén (*Warehouse Management System*). |
| Referencia / SKU | Artículo distinto gestionado en el almacén. |
| Número de serie | Identificador único de cada unidad física de un artículo. |
| Ubicación | Posición física identificada del almacén donde se guarda mercancía. |
| *Picking* | Preparación de pedidos: extracción de mercancía de sus ubicaciones. |
| Expedición | Salida de mercancía preparada hacia el cliente. |
| MVP | Producto mínimo viable (*Minimum Viable Product*): primera versión con lo imprescindible para trabajar. |
| ERP | Sistema de gestión de la empresa (compras, ventas, facturación…). |
| ADR | Registro de una decisión de arquitectura o funcional (*Architecture Decision Record*). |
| Unidad | Cada pieza física identificada por su número de serie. Un pack que se maneja entero es una sola unidad. |
| Zona | Área del almacén (recepción, picking, reserva, expedición…) que agrupa ubicaciones. |
| Zona de picking | Zona asignada a un artículo para su preparación. |
| Contenedor | Palet, caja o bulto con etiqueta propia que se mueve de un solo escaneo. |
| Matrícula / SSCC | Código que identifica un contenedor. SSCC es el estándar GS1 de 18 dígitos. |
| Bulto | Contenedor en el que se embala un pedido para su expedición. |
| Oleada | Agrupación de varios pedidos para prepararlos en una misma ronda de *picking*. |
| Reserva | Cantidad de stock comprometida para un pedido liberado y todavía no preparada. |
| Movimiento | Registro inmutable de cada operación sobre una unidad (quién, cuándo, de dónde a dónde). |
| Recuento cíclico | Inventario parcial, por zonas, que se hace de forma periódica sin parar el almacén. |
