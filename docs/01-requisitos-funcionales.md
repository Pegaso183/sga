# 01 · Requisitos funcionales

```
### RF-XXX · Título
- Módulo:

  - [ ] …
- Prioridad: MVP / Posterior
```

- Ubicación

- Preparación de pedidos (*picking*)
- Expedición
- Devoluciones
- Maestros (artículos, ubicaciones, clientes, proveedores, usuarios)
