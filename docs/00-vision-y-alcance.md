# 00 · Visión y alcance

## Visión
Disponer de un sistema propio que gestione todas las operaciones del almacén de distribución B2B,
tomando como referencia las funcionalidades de los WMS mejor valorados del mercado.

## Contexto conocido
- Un único almacén de distribución (logística B2B), para uso propio.
- ~4.000 referencias y ~20 operarios.
- Trazabilidad por número de serie; sin control de caducidades.
- Buena cobertura wifi en el almacén.

## Dentro del alcance (borrador, pendiente de validar)
- Recepción de mercancía
- Ubicación y gestión de huecos
- Inventario y trazabilidad por número de serie
- Preparación de pedidos (*picking*)
- Expedición
- Devoluciones
